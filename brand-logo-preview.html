Header Logo Implementation Rules • Production CSS

  • Header Height: 72–84px on desktop, 60–72px on mobile.
  • Logo Height Constrained: 38–42px on desktop, 28–32px on mobile.
  • Width Auto: Always specify width: auto; with height: constrained;. Never stretch!
  • No Cheap Clipart: No yellow roofs, checkerboards, cartoon cars, or giant fake shields.
/* Recommended Production CSS for Website Header */ .site-header { height: 78px; background-color: #0B0D12; border-bottom: 1px solid rgba(197, 160, 89, 0.2); display: flex; align-items: center; justify-content: space-between; padding: 0 clamp(16px, 4vw, 36px); } .site-header .brand-logo { height: 40px; /* Constrained height */ width: auto; /* Preserves 5.28:1 aspect ratio */ display: block; } @media (max-width: 768px) { .site-header { height: 64px; } .site-header .brand-logo { height: 30px; /* Renders at ~158px width */ } }
